# Crop Yield Gap Diagnosis Platform

Explainable ML platform for crop yield gap diagnosis and fertilizer optimization across 105 crops and 33 Indian states.

**Model:** XGBoost | **R² = 0.9976** | **CV R² = 0.9933** | **212,901 records**

---

## Installation

### 1. Clone the repo
```bash
git clone https://github.com/aayushpradhan19-a11y/Crop-yield-gap-platform.git
cd Crop-yield-gap-platform
```

### 2. Create virtual environment
```bash
python -m venv venv

# Windows:
venv\Scripts\activate

# Mac/Linux:
source venv/bin/activate
```

### 3. Install libraries
```bash
pip install -r requirements.txt
```

### 4. Set up Kaggle API
1. Go to kaggle.com > Account Settings > API > Create New Token
2. Save the downloaded `kaggle.json` to:
   - Windows: `C:\Users\YourName\.kaggle\kaggle.json`
   - Mac/Linux: `~/.kaggle/kaggle.json`

### 5. Download raw datasets
```bash
kaggle datasets download -d abhinand05/crop-production-in-india -p data/raw --unzip
kaggle datasets download -d atharvaingle/crop-recommendation-dataset -p data/raw --unzip
```

### 6. Run preprocessing
```bash
python notebooks/stage3_yield_gap.py
```
Expected: `Final master dataset: (212901, 18)` — takes ~3-4 min.

### 7. Train the model
```bash
python notebooks/stage5_model.py
```
Expected: `R² : 0.9976` | `Model saved: models/xgb_yield_gap.pkl` — takes ~4-5 min.

### 8. Launch the app
```bash
streamlit run app/app.py
```
Opens at **http://localhost:8501**
